# Strings: Extraindo Palavras-Chave de um Texto

## Descrição
Este projeto tem como objetivo extrair palavras-chave de um texto utilizando Python. O programa analisa as palavras, remove termos comuns e identifica as palavras mais frequentes.

## Objetivos
- Praticar manipulação de strings.
- Utilizar expressões regulares.
- Contar palavras de um texto.
- Identificar palavras-chave relevantes.

## Funcionalidades
- Receber um texto digitado pelo usuário.
- Converter o texto para letras minúsculas.
- Remover palavras comuns.
- Contar a frequência das palavras.
- Exibir as palavras-chave encontradas.

## Tecnologias Utilizadas
- Python 3
- Biblioteca re
- Biblioteca collections

## Como Executar
1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python main.py
```
